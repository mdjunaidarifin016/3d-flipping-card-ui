# 💳 3D Flipping Credit Card UI

A modern and interactive 3D credit card interface built using pure HTML and CSS. The card features a smooth flip animation, glassmorphism styling, gradient background effects, and front and back card layouts.

## ✨ Features

- Interactive 3D card flip animation on hover
- Front and back credit card designs
- Glassmorphism effect using `backdrop-filter`
- Gradient background with CSS pseudo-elements
- Smooth 3D rotation using CSS transforms
- Card details including number, holder name, and expiry date
- Magnetic strip and signature section on the back
- Clean and modern UI design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder.
3. Open `index.html` in your browser.
4. Hover over the card to see the 3D flip animation.

## 🧠 CSS Concepts Practiced

- CSS Flexbox
- CSS Positioning
- Pseudo-elements (`::before` and `::after`)
- CSS Transforms (`rotateY`)
- 3D Transformations (`transform-style: preserve-3d`)
- `backface-visibility`
- Glassmorphism (`backdrop-filter`)
- Linear and repeating gradients
- CSS Transitions

## 🎯 Purpose

This project was created to improve my understanding of advanced CSS styling, 3D transformations, positioning, pseudo-elements, and animation effects.
